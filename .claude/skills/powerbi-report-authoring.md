Aide à créer ou modifier un rapport Power BI de A à Z.

## Ce que ce skill fait

1. Analyse le besoin métier ou les données disponibles
2. Propose une structure de rapport (pages, hiérarchie de navigation)
3. Recommande les visuels adaptés à chaque cas d'usage
4. Génère les expressions DAX nécessaires pour les mesures
5. Configure les interactions entre visuels

## Comment l'utiliser

Décris ce que tu veux construire :
- Quel est l'objectif du rapport ?
- Quelles données sont disponibles (tables, colonnes clés) ?
- Qui est l'audience (direction, opérationnel, technique) ?

## Exemples de tâches

- "Crée un rapport de suivi des ventes par région et par mois"
- "Ajoute une page de détail sur les clients inactifs"
- "Génère les mesures DAX pour le calcul du chiffre d'affaires YTD"
