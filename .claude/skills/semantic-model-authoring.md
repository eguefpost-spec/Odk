Crée et optimise des modèles sémantiques (anciennement datasets) pour Power BI et Microsoft Fabric.

## Ce que ce skill fait

1. Conçoit le schéma en étoile (fait + dimensions) adapté aux données
2. Génère les relations entre tables (cardinalité, direction du filtre)
3. Rédige les mesures DAX (KPIs, calculs temporels, ratios)
4. Configure les hiérarchies, groupes d'affichage et dossiers
5. Optimise les performances (agrégations, colonnes inutiles, types de données)

## Comment l'utiliser

Fournis :
- Le schéma de tes tables sources (noms, colonnes, clés)
- Les métriques métier à calculer
- Le volume de données estimé

## Exemples de tâches

- "Crée un modèle en étoile à partir de ces 5 tables SQL"
- "Écris une mesure DAX pour le CA glissant sur 12 mois"
- "Optimise ce modèle qui met 30s à se rafraîchir"
- "Configure le modèle sémantique pour Microsoft Fabric avec DirectLake"
